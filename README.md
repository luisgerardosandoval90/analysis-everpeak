Análisis de Datos – Curso Analista de Datos

Este repositorio contiene el análisis de datos desarrollado como parte de las actividades prácticas del curso de Analista de Datos.

El proyecto aborda la exploración, limpieza, procesamiento y análisis de un conjunto de datos para extraer insights valiosos y responder a preguntas clave de negocio.

📂 Contenido del repositorio

notebooks/analisis_datos.ipynb
→ Notebook principal que incluye la carga de datos, limpieza, análisis exploratorio (EDA), visualizaciones y conclusiones clave.

▶ Cómo abrir el notebook en Google Colab

Haz clic en el siguiente botón: https://colab.research.google.com/drive/1sGgIFENuwsFx9JQp43qmapyqIKT1QNVa?usp=sharing

O bien:

Abre el archivo .ipynb directamente en GitHub.

Haz clic en el botón Open in Colab que aparece en la parte superior del visor de notebooks.

📘 Cómo reproducir el análisis

Abre el archivo en Google Colab o en tu entorno local de Jupyter.

Ejecuta las celdas de código en orden secuencial.

El notebook está diseñado para cargar los datasets necesarios de manera automática desde las rutas especificadas o fuentes públicas.

🧠 Objetivos del análisis

Explorar la estructura y calidad del conjunto de datos.

Aplicar técnicas de limpieza y transformación de datos.

Descubrir patrones, distribuciones y relaciones relevantes mediante visualizaciones.

Comunicar hallazgos y recomendaciones basadas en evidencia analítica.
